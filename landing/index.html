A Panorama shell for Deadlock

Your HUD,
with windows.

Openlock is a window manager that runs over the live game. It frames Deadlock's own panels without reparenting them, adds a taskbar, toasts and a workspace, and mounts XML windows delivered by Deadworks addon packages.

One file, next to the game.

The release script downloads a verified archive, checks its SHA-256, and installs into a private addon root. It never overwrites a VPK owned by a mod manager.

01

Download install.ps1

Take it from the latest GitHub release. The player VPK and checksum are published beside it.

02

Drop it in game/bin/win64

That is the folder holding deadlock.exe. The script finds the install from its own location.

03

Close Deadlock and run it

The shell window appears, verifies the release, writes citadel/addons/mods to SearchPaths, and leaves the game's other addon folders untouched.

04

Start Deadlock

The shell boots from its own archive. No server or plugin is required for the UI.

If PowerShell refuses the file, right-click it and choose “Run with PowerShell”, or run powershell -ExecutionPolicy Bypass -File install.ps1 from that folder.

Addons bring their own windows.

Deadworks packages are shploingus SHPKG002/SHPKG003 frames. The shell verifies the frame digest before reading the recipe, then mounts only XML the archive actually carries.

Real package format

The recipe is shploingus.recipe/3, with the same window grammar as the shploingus display package. No second manifest.

VPK first

Ship the package and its XML inside a VPK. A loose .shpkg is discovered, but its XML is not mounted unless the VPK carries it.

Observer surfaces

A package XML can be addressed as a toast in observer grade. Its layout receives live build, update and connection data on dw_observer_data.

Pick the shell that fits.

The grade is recorded at install time. The player release is baked in player mode so a fresh install restores the saved layout scheme without a server.
