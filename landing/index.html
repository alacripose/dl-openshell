A Panorama shell for Deadlock

Your HUD,
with windows.

dl-openshell is a window manager that runs over the live game. It frames Deadlock's own panels without reparenting them, adds a taskbar, toasts and a workspace, and mounts XML windows delivered by Deadworks addon packages.

One file, next to the game.

The release script downloads a verified archive, checks its SHA-256, and installs into a private addon root. It never overwrites a VPK owned by a mod manager.

01

Download install.cmd and install.ps1

Take both from the latest GitHub release, next to the player VPK, checksum and MIT license.

02

Drop it in game/bin/win64

That is the folder holding deadlock.exe. The script finds the install from its own location.

03

Close Deadlock and double-click install.cmd

The shell window appears, asks for the shell grade, verifies the release, writes citadel/addons/mods to SearchPaths, and leaves the game's other addon folders untouched.

04

Start Deadlock

The shell boots from its own archive. No server or plugin is required for the UI.

Windows marks downloaded scripts, and the default policy refuses to run them before they start. install.cmd applies a process-scoped bypass for you. To run install.ps1 directly, first right-click it → Properties → Unblock, then choose “Run with PowerShell”, or run powershell -ExecutionPolicy Bypass -File install.ps1 from that folder.

Addons bring their own windows.

Deadworks packages are shploingus SHPKG002/SHPKG003 frames. The shell verifies the frame digest before reading the recipe, then mounts only XML the archive actually carries.

Addons are data, not a second build: one entry in landing/tools/addons.json adds a card here. The card carries the package name, version, author, target build and links to the download or source.

Pick the shell that fits.

The grade is recorded at install time. The player release is baked in player mode so a fresh install restores the saved layout scheme without a server.
